# Правила проекта

## Обязательные файлы (читать перед работой)
- `WORKFLOW.md` — правила работы, отчёты, разбор проблем.
- `DESIGN.md` — шрифты, цвета, пропорции экрана камеры.
- `ARCHITECTURE.md` — стек, архитектура, хранение файлов, карта.
- `TECH_DEBT.md` — список известных проблем и рефакторингов.
  **НЕ ВЫПОЛНЯТЬ** без явной команды пользователя. Только для контекста.

## Главное
1. Пиши код только в этом проекте.
2. По команде «коммить» — коммит и push.
3. Сообщения коммитов на русском: «тип: краткое содержание».
4. Перед коммитом — сборка `./gradlew assembleDebug`.
5. Если что-то непонятно — сначала спроси.

## Запрещено
- Deprecated API: старый Camera API, синхронный `Geocoder.getFromLocation()`, `WRITE_EXTERNAL_STORAGE`.
- Новые библиотеки без явного указания.
- Менять `minSdk`, `targetSdk`, `compileSdk` без указания.
- Менять координаты библиотек (`io.coil-kt` → `io.coil-kt.coil3`).
- Трогать файлы, не относящиеся к задаче.
- Генерировать несуществующие API.

## После каждого шага
- Сборка: `./gradlew assembleDebug`.
- Показать результат (успех или полный текст ошибок).
- Не переходить к следующему шагу, если сборка упала.
